# Jotter

Save notes and conversation context from one AI assistant and load them into
another (ChatGPT, Claude, Gemini). Explicit saves only, text only, private to
you — nothing is captured unless you ask, and nothing ever auto-deletes.

## Installing in Cursor

1. Open **Customize** in Cursor's sidebar.
2. Find **Jotter** in the marketplace.
3. Select **Install**.
4. Complete the OAuth sign-in when prompted.

This plugin only points your agent at the hosted Jotter MCP server
(`https://jotter.fyi/mcp`) — no code runs locally.

## Installing in Antigravity

```sh
agy plugin install https://github.com/HelixMediaLabs/jotter-plugin
```

Sign in when the browser opens. Then say "jot this" to save, or
"Continue my last handoff".

## Installing in Gemini CLI

```sh
gemini extensions install https://github.com/HelixMediaLabs/jotter-plugin
```

Sign in when the browser opens on first use.

## Getting started

Once installed, just talk to it:

> "Jot this conversation so I can pick it up elsewhere."

> "Load my latest jot and continue where we left off."
